# How to use it

The code is almost the same as the code used in seq2seq. 
The only difference is we replace the encoder's LSTM model with a simple Transformer block.

1. Activate your virtual python environment.
2. Get into the work directory. You should run all code inside the work directory

Work directory means the directory that has all the following files:
- dataset.py
- model.py
- test.py
- train.py
- toy_dataset.csv
